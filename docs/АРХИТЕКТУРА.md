# Как устроена лаборатория

## Идея в одном абзаце

Лаборатория — это папка с текстовыми правилами, которые читает Claude Code. Никакого сервера
и установки: вы открываете разговор в этой папке, помощник читает `CLAUDE.md` + свой мандат
в `coordinators/` и работает по протоколу. Всё, что он делает, остаётся файлами у вас на диске.

## Карта папок

```
CLAUDE.md              — правила для помощника (главный файл, читается всегда)
PROTOCOL.md            — рабочий цикл сессии
ДОБРО_ПОЖАЛОВАТЬ.md    — инструкция для человека
START_HERE.command     — кнопка первого запуска
config/lab.yaml        — имена, обращение, настройки (заполняется при онбординге)
coordinators/          — мандаты направлений (кто чем занимается)
  library · portal · infra · content · _template (для новых направлений)
work/                  — рабочие файлы по направлениям
  library/ portal/ infra/ content/
examples/              — 4 готовых прогона типовых задач
lessons/УРОКИ.md       — 15 уроков из реальных граблей
notes/                 — дневник: что сделано, решено, ждёт решения
INBOX/                 — входящие файлы (помощник разбирает в начале сессии)
```

## Почему направления — отдельные сессии

У помощника ограниченная «оперативная память» разговора. Если в одной сессии смешать каталог,
код портала и бэкапы — он начнёт терять контекст и путаться. Одно направление — один разговор,
названный именем координатора. Передача между направлениями — явной фразой (см. PROTOCOL.md §5).

## Как добавить новое направление

1. Скопируйте `coordinators/_template.md` → `coordinators/<название>.md`, заполните мандат.
2. Создайте папку `work/<название>/`.
3. Впишите координатора в `config/lab.yaml`.
4. Откройте под него отдельную сессию и переименуйте её.

## Память лаборатории

- **`notes/`** — то, что помощник записывает после каждой задачи. Это то, чем сессии
  «помнят» друг друга: новый разговор читает последние записи и входит в курс.
- **git** — включается при первом запуске (`START_HERE.command`), хранит историю изменений
  локально. Ничего никуда не отправляет, пока вы сами не подключите удалённый репозиторий.

## Границы — что лаборатория НЕ делает

- Не принимает духовных решений и не заменяет живого учителя.
- Не тратит деньги, не публикует наружу, не удаляет файлы без вашего явного «да».
- Не правит слово Гуру в расшифровках — только помечает сомнительное для живой вычитки.
- Не хранит пароли и токены в чате или в коде.

## Связь с большой лабораторией

Каркас собран по образцу рабочих лабораторий миссии. Уроки в `lessons/УРОКИ.md` — общий актив: они выстраданы на реальных граблях
и применимы одинаково. Если у вас появится свой урок — допишите его туда же.
