# DevoteeLab — личная мультиагентная лаборатория

**Актуальный переносимый каркас v2.0 — 24 ноября 2026.**

## Один файл для передачи Claude Code или Codex

### [Открыть START-LAB.txt](START-LAB.txt)

Передайте нейросети ссылку на этот файл или скачайте его через **Raw / Download** и приложите к сообщению. Готовая первая фраза владельца находится в начале файла.

Внутри — главный Dev-координатор, координаторы проектов, разведчик, помощник по устройствам, автор и проверяющий; шесть навыков, задания и квитанции между исполнителями, продолжение после компакта, закрытая память GitHub и настоящий Vault. Есть путь настройки с нуля и рабочий цикл для книг с двух планшетов.

Вместе с каркасом передаются **239 обезличенных исторических разборов, 50 мер против повторения ошибок и 17 позднейших уточнений**. Это покрытие зафиксированного общего журнала, а не публикация частных переписок. Ошибочные выводы и их опровержения сохранены. История не является текущим разрешением, а прежнее исправление не означает повторную проверку всех старых систем.

Публичный репозиторий содержит шаблон. Личные рукописи, память и рабочие результаты должны находиться в отдельном проверенном **закрытом** репозитории. Секреты не хранятся даже в закрытом Git.

Пакет подготовлен для совместимых режимов Claude Code; основной договор работы переносим в Codex. Загрузка навыков, исполнение агентов, подключение памяти и доступ с планшетов проверяются в аккаунте получателя. Наличие файлов само по себе не подтверждает работающую установку.

- [Манифест и хеш пакета](START-LAB.manifest.json)
- [Необязательное безопасное извлечение](extract_lab.py) — Python 3, без сети и установки программ
- [Состав исторического покрытия](lessons/HISTORY-COVERAGE-v2.json)
- [Проверки опубликованной сборки](checks/lab-v2-packaging.json)

Для проверки без записи: `python3 extract_lab.py START-LAB.txt --check`. Для извлечения в ещё не существующую папку: `python3 extract_lab.py START-LAB.txt personal-lab`. Затем следуйте START.md. Никакого отключения системной защиты или безусловного обновления чужого дерева не требуется.

# Каркас лаборатории для преданного

Готовая папка-заготовка, чтобы вести свои проекты вместе с AI-помощником (Claude Code):
структура, правила, координаторы направлений, примеры типовых задач и свод уроков.

Собрано в лаборатории Арджуны и отдано общине как есть — берите и пользуйтесь.

## Как начать

1. Установите **Claude Code** — https://claude.com/claude-code — и войдите в аккаунт.
2. Скачайте каркас:
   ```
   git clone https://github.com/PrabhuArjun/DevoteeLab.git моя-лаборатория

> ⚠️ **Берите каркас именно этой командой, а не кнопкой «Download ZIP».**
> macOS помечает всё скачанное браузером как «от неустановленного разработчика»
> и не даёт запустить `START_HERE.command` двойным щелчком. У склонированной
> папки такой метки нет, и всё запускается сразу.
>
> Если всё же скачали архивом и запуск заблокирован — правый клик «Открыть»
> в свежих macOS больше НЕ помогает, Apple этот способ убрала. Рабочий способ,
> один раз на папку: откройте Терминал, наберите `xattr -dr com.apple.quarantine `
> (с пробелом в конце, Enter не нажимайте), перетащите в окно папку лаборатории
> и нажмите Enter.
   ```
3. Откройте папку и дважды щёлкните **`START_HERE.command`**.
4. Помощник представится и задаст несколько вопросов: как его называть, как обращаться к вам,
   как удобнее общаться (технически или простыми словами), как назвать помощников по направлениям.

Дальше — файл **`ДОБРО_ПОЖАЛОВАТЬ.md`**.

## Что внутри

- **4 направления** (можно переименовать под свой проект): Библиотека · Портал · Инфраструктура · Контент
- **Примеры типовых задач** — включая совместное написание кода словами
- **15 уроков** из реальных граблей: «покажи уроки»
- **Правила бережности:** помощник не духовный авторитет · машина не правит слово Гуру ·
  публикация и траты — только с вашего явного «да» · пароли не в чат

## Обновления

Каркас улучшается. Чтобы получить свежую версию — в папке лаборатории:

```
git pull
```

**Ваша работа не пострадает:** настройки, дневник, рабочие файлы и входящие в обновление не входят.
Подробности — `ОБНОВЛЕНИЕ.md`.
