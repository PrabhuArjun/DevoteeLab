# Каркас лаборатории для преданного

Готовая папка-заготовка, чтобы вести свои проекты вместе с AI-помощником (Claude Code):
структура, правила, координаторы направлений, примеры типовых задач и свод уроков.

Собрано в лаборатории Арджуны и отдано общине как есть — берите и пользуйтесь.

## Как начать

1. Установите **Claude Code** — https://claude.com/claude-code — и войдите в аккаунт.
2. Скачайте каркас:
   ```
   git clone https://github.com/PrabhuArjun/DevoteeLab.git моя-лаборатория
   ```
3. Откройте папку и дважды щёлкните **`START_HERE.command`**.
4. Помощник представится и задаст несколько вопросов: как его называть, как обращаться к вам,
   как удобнее общаться (технически или простыми словами), как назвать помощников по направлениям.

Дальше — файл **`ДОБРО_ПОЖАЛОВАТЬ.md`**.

## Что внутри

- **4 направления** (можно переименовать под свой проект): Библиотека · Портал · Инфраструктура · Контент
- **Примеры типовых задач** — включая совместное написание кода словами
- **15 уроков** из реальных граблей: «покажи уроки»
- **Правила бережности:** помощник не духовный авторитет · машина не правит слово Гуру ·
  публикация и траты — только с вашего явного «да» · пароли не в чат

## Обновления

Каркас улучшается. Чтобы получить свежую версию — в папке лаборатории:

```
git pull
```

**Ваша работа не пострадает:** настройки, дневник, рабочие файлы и входящие в обновление не входят.
Подробности — `ОБНОВЛЕНИЕ.md`.
